## 2. 原项目需要迁移什么

“重写完成”不能仅指 CMake 能编译或能显示下落动画。至少保留并验收：

- **单元数学：** 二维材料嵌入三维的变形梯度、NH 能量、解析梯度/Hessian、厚度与 SI 单位、对数延拓和完全退化拒绝。
- **网格、质量与约束：** 原拓扑、统一 X-Z 场景约定、集中/一致质量、固定点与自由度映射；各求解路径保留对应质量模式。
- **隐式路径：** 增量目标、稠密小规模参考和稀疏路径、Newton、线搜索、对角修正、求解内法向罚接触及后续摩擦。
- **距离约束 XPBD：** 距离、剪切、原有弯曲约束、顺序更新语义、乘子和柔度、步后接触。
- **单元能量约束 XPBD：** 原 C = E / energy_scale 定义、梯度与乘子更新、退化行为；不因共享 NH 能量就声称与隐式路径材料等价。
- **场景运行：** 原初态、固定边、重力、步长、接触/摩擦开关、统一推进与保存频率；位置、速度、能量、应力、残差、迭代、接触和耗散记录。
- **实验与运行接口：** 无窗口 CLI、可保存配置、机器可读结果、可复现基准、失败退出码和运行说明。

原实现的已知风险要登记处理：有限状态不等于 XPBD 收敛；研究脚本可能打印失败却正常退出；接触投影可能移动固定点；未收敛步可能继续接受；采样步耗时不能代表全程。不能将这些风险静默照抄为验收定义；改进旧行为时也不能再要求对应输出逐位相同。每项语义修正都需要单独解释、测试和讲义记录。

## 5. 扩展阶段的接触几何合同

本节为迁移后的设计，不要求现在为未来所有形状预建空接口。通用结果可包含 A/B 标识、两侧见证点 pA/pB、单位法向 n、有符号 gap、特征与状态。

**n 从 A 指向 B；gap = dot(pB - pA, n)；分离为正，穿透为负。** 法向冲量对 B 为 +jn*n，对 A 为 -jn*n。例如 A 为球、B 为地面，地面允许半空间法向向上时，统一接触法向向下；解析形状公式需转换为统一约定。

球心重合时法向不唯一，应返回状态或采用有文档的确定性策略，不直接除零。几何只回答接近与特征，不修改速度；质量、惯量、摩擦、恢复系数和步长接受属于响应层。

刚体需要流形与持久特征，布料自碰撞需要顶点–三角形/边–边和薄壳两侧语义，流体边界还涉及核支持、密度与压力/黏性。可共享几何与加速结构，但不强求相同求解器。AABB/BVH 不替代窄相，GJK/EPA 不自动覆盖任意凹网格，离散检测不保证高速运动不穿隧。

## 6. 流体与双向耦合的学习边界

首个流体模块从小规模 SPH 开始：邻域、密度、压力/黏性、边界交换、积分、诊断。采用弱可压缩状态方程时如实标明近似；声速、压力刚度和稳定步长关联，不能只凭一帧动画判断精度。

静态壁面不能只靠穿透后投影：核支持缺失、密度、压力和黏性边界需要明确处理。先做常量场/密度、静水、质量与粒子对反作用，再做复杂流动。后续按同场景误差学习 DFSPH；MAC、压力投影和 PIC/FLIP 是独立专题，不同时铺开。它们是教学取舍，不是对所有流动的优劣判断，也不是工程 CFD 能力承诺。

真正双向耦合需要同一笔交换量：一方收到 J，另一方收到 -J；刚体还收到关于质心的角冲量 r × J。多点分配同时检查合力与力矩。布料重心权重之和为 1、加权节点位置等于交换点，才有相应的线/角冲量匹配条件。

分区求解从同步子步和明确交换账开始；强耦合可能需要界面迭代。轻结构–近不可压流体的附加质量效应、薄膜漏流、滞后载荷和时间尺度差异，不能靠“力相反”自动解决。

验收包括：

- 无外部作用时检查总线/角动量；有重力、夹持边、无限质量地面或运动学驱动时，把外部交换计入。
- 能量区分储能、物理耗散、数值耗散与外部做功；不把无法解释的增长一律归因于数值误差。
- 检查穿透、漏流、密度误差、滑移、残差和子步/迭代趋势。
- NaN、退化、未收敛、回退与超限成为明确状态和失败材料。

水推布但布不反推水属于单向作用，可作前置实验；吸水、湿布增重、孔隙流动、毛细、导热和相变都需要额外模型，不由碰撞自动产生。
